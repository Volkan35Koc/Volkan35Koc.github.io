## Selected Projects

### 1. Coffee Sales Analysis
**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn

An exploratory analysis of coffee sales data focused on revenue patterns, product categories, and sales trends.

- Checked missing values, duplicate records, and invalid or negative values.
- Examined revenue and product-category performance.
- Analyzed sales patterns by weekday and hour.
- Used moving averages and heatmaps to explore trends.
- Exported processed data and analysis outputs.

### 2. Wine-Tasting Scores — Regression Analysis
**Technologies:** Python, Pandas, Scikit-learn, Regression Models

A regression project exploring the prediction of wine-tasting scores and comparing model performance.

- Prepared data for regression analysis.
- Evaluated Linear Regression, Decision Tree, K-Nearest Neighbors, and Random Forest models.
- Compared models using MAE, RMSE, and R².
- Recorded a Random Forest R² score of 0.523 and cross-validation R² of 0.642 ± 0.028 in the reported experiments.

- Extracted audio features, including MFCCs.

- Used a Random Forest classifier.
- Achieved 80.3% accuracy in the reported evaluation.
